# Milestones

## Overview

Development roadmap for the Story-Powered proof of concept (2 chapters).

---

## Milestone 1: Core Framework

**Status**: Starting

**Goals**:
- [ ] Project directory structure
- [ ] Autoload singletons (GameManager, SceneLoader, DataManager)
- [ ] JSON loading and parsing system
- [ ] Base scene rendering (background + positioned elements)
- [ ] Percentage-based coordinate system working on screen
- [ ] Basic scene transitions

**Deliverable**: Can load a chapter JSON and display static scenes with transitions.

---

## Milestone 2: Interaction System

**Status**: Not started

**Goals**:
- [ ] Base interaction class/interface
- [ ] Implement first 3-4 interaction types
- [ ] Interaction completion detection
- [ ] Auto-advance after interaction + animation
- [ ] JSON-driven interaction configuration

**Deliverable**: Scenes with working interactions that auto-advance.

---

## Milestone 3: Content & Polish

**Status**: Not started

**Goals**:
- [ ] Implement remaining interaction types
- [ ] Chapter 1 content (scenes, assets, JSON)
- [ ] Chapter 2 content
- [ ] Chapter selection menu
- [ ] Scene transition animations
- [ ] Audio integration (music + sfx)

**Deliverable**: Two playable chapters with full content.

---

## Milestone 4: Mobile & Export

**Status**: Not started

**Goals**:
- [ ] Android export configuration
- [ ] iOS export configuration
- [ ] Touch input testing on devices
- [ ] Performance optimization
- [ ] Safe area handling (notches, etc.)

**Deliverable**: Installable builds for Android and iOS.

---

## Proof of Concept Complete

All milestones done = 2 playable chapters on mobile devices.
