# Session 05 — 2026-02-19

## Summary
Extended Prototype 2 (cleaning room) with a "tidy" mode and built Prototype 3 (bring into focus) from scratch.

## What We Did

### Prototype 2: Tidy Mode
- Added a second interaction mode to the tap-to-clear engine: items can now be **removed** (disappear) or **tidied** (swap graphic + slide to neat position)
- `tappable_item.gd`: new `item_mode` property ("remove" / "tidy"), tidy target state (`tidy_position`, `tidy_color`, `tidy_size`, `tidy_texture`), tidy animation (bounce → swap visual → slide to position)
- `tap_to_clear_engine.gd`: reads `mode` and tidy fields from JSON, extracted `_pct_to_px()` helper
- `cleaning_room.json`: clothes, books, shoe, bag → tidy mode; cup, wrapper, magazine → remove mode
- Discussed unpacking mechanic (items start clustered in a container, tap to place in scene) — concluded it's the same engine with different JSON layout, no new prototype needed

### Prototype 3: Bring Into Focus
- Built complete slider-based focus puzzle with 3 difficulty levels
- **Level 1**: Single slider — blur/focus only
- **Level 2**: Two sliders — double-vision alignment + focus
- **Level 3**: Three sliders — alignment + focus + wave distortion
- Custom GLSL shader (`focus_shader.gdshader`) with blur, offset, and distortion uniforms
- Reusable engine auto-advances through levels after 0.4s hold at correct values
- Uses `icon.svg` as placeholder image — swap path in JSON to use real artwork
