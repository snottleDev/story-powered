## Summary

Refactored Prototype 1 (suitcase packing) into a reusable drag-drop puzzle engine driven by JSON config. Added optional texture support with placeholder fallback. Fixed display scaling for iPhone.

## What Was Accomplished

### Drag-Drop Puzzle Engine Refactor
- **Extracted puzzle data** into `suitcase_puzzle.json` with percentage-based positions
- **Created reusable engine** `drag_drop_puzzle.gd` + `drag_drop_puzzle.tscn` — loads JSON, creates zones/items, tracks completion, emits `puzzle_completed` signal
- **Simplified suitcase_packing.gd** to thin visual wrapper — builds suitcase backdrop, sets puzzle/items areas, hands off to engine
- **`draggable_item.gd` unchanged** — already generic enough
- Engine accepts any number of items (not limited to 5)
- Parent scene controls zone placement via `set_puzzle_area(Rect2)` and item scatter via `set_items_area(Rect2)`

### Optional Texture Support
- Items can specify `"texture": "res://path/to/image.png"` in JSON
- When texture exists: renders Sprite2D, derives `item_size` from image automatically
- When texture missing or not specified: falls back to colored rectangle placeholder with label
- Missing textures are visible (colored boxes) without breaking the game

### Display Scaling Fix
- Changed `project.godot` stretch aspect from `"expand"` to `"keep"`
- Fixes white background not covering full screen on modern iPhones (taller than 16:9)
- Viewport stays exactly 1080x1920 with black bars on taller devices

### Verified on Device
- Refactored suitcase scene runs identically to original on iPhone

## Decisions Made
- JSON + reusable engine + visual wrapper per puzzle (three-part architecture)
- Positions are percentage-based (0.0–1.0), converted to pixels at runtime
- Individual textures over sprite sheets — sufficient for simple puzzle scenes
- `"keep"` stretch mode for consistent visual layout across devices

## How to Create a New Puzzle
1. Write a JSON file defining items, zones, and text
2. Create a visual wrapper scene (backdrop + area rects)
3. Instance the engine, set areas, call `load_puzzle()`. Done.
