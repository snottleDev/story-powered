### Prototype 4: Memory Game
- Classic memory/matching card game with flip animation
- Cards flip via X-scale tween (squash → swap face/back → expand)
- Supports both identical and conceptual matching (pairs share a `pair_id` regardless of label)
- Grid auto-sizes from pair count: `columns = ceil(sqrt(total_cards))` when not specified in JSON
- Demo JSON: 6 conceptual pairs (Revenue↔$$$, Deadline↔Clock, etc.)
- Green felt table backdrop

### Prototype 5: Polaroid Reveal
- One-at-a-time polaroid development: swipe down to develop, then pin to board
- Swipe-down detection with minimum vertical distance and horizontal drift limit
- White overlay fades in stages (4 swipes to fully develop)
- Developed polaroid animates (shrink + fly + rotate) to pin position on corkboard
- Pinned photos accumulate visually on the board
- Device shake support via `Input.get_accelerometer()` with cooldown
- Shake feedback: horizontal wiggle animation on each swipe

### Prototype 6: Painting Reveal
- Scratch-card style brush reveal using Image-based mask + shader
- Half-resolution mask (L8 format) for performance
- Brush stamps interpolated along drag path to prevent gaps
- Cover shader: mask white = opaque cover, mask black = transparent (image shows through)
- Auto-completes when 80% revealed — remaining cover fades away
- Fixed image overflow issue: switched to `EXPAND_IGNORE_SIZE` + `STRETCH_KEEP_ASPECT_COVERED`
